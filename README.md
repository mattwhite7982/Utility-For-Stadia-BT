# Stadia Bluetooth Mode Checker for Android

A specialized utility to verify the firmware status of Google Stadia Controllers directly from an Android device. 

## Overview
Following the shutdown of the Stadia service, many controllers remain in Wi-Fi mode. This app provides a mobile-first solution to check if a controller has been successfully flashed to Bluetooth Low Energy (BLE) mode.

## Features
* **USB & Bluetooth Discovery:** Detects controllers via USB OTG or wireless scanning.
* **Firmware Validation:** Identifies Product IDs (PID) to distinguish between Stadia and Bluetooth modes.
* **Connection Guide:** Integrated tips for putting the controller into pairing mode.
